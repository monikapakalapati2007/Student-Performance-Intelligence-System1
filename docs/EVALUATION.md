# Evaluation report

All numbers below were measured on this machine and are stored verbatim in
`results/metrics.json`, `results/run_results.json` and `models/student_performance/model_config.json`.
Nothing here is estimated.

## Primary regression model — `total_score`

Final `HistGradientBoostingRegressor` refit on 850,000 rows (train + validation), evaluated once
on 150,000 unseen test rows:

| metric | value |
|---|---|
| MAE | **6.119 points** |
| MSE | 67.346 |
| RMSE | **8.206 points** |
| R² | **0.7175** |
| target mean ± SD | 84.29 ± 15.44 |
| predictions outside 0–100 | 0 |
| n | 150,000 |

Validation (before the refit, 150,000 rows): MAE 6.118, RMSE 8.221, R² 0.7165. Test and
validation agree, so there is no sign of overfitting.

Interpretation: the model explains ~72 % of score variance and is typically off by ~6 points.
A large share of the residual is irreducible: 26.8 % of scores are exactly 100, so students
above the ceiling cannot be distinguished.

## Grade classifier — behaviour features only

| metric | value |
|---|---|
| accuracy | **0.6956** |
| weighted F1 | 0.6869 |
| macro F1 | 0.4536 |

Confusion matrix (rows actual F, D, C, B, A):

| actual \ predicted | F | D | C | B | A |
|---|---|---|---|---|---|
| F | 7 | 611 | 303 | 9 | 0 |
| D | 19 | 2,381 | 3,629 | 702 | 19 |

Rare grades collapse into their neighbours, which is expected: with the score hidden, the three
behaviour features barely separate F/D/C. The ranking quality (AUC 0.90) is much better than
the hard-label accuracy.

## Feature importance (permutation, test split)

Increase in RMSE when the feature is shuffled:

| feature | Δ RMSE (points) |
|---|---|
| `weekly_self_study_hours` | **11.7356** |
| `participation_per_study_hour` | 0.0066 |
| `study_attendance_product` | 0.0058 |
| `effort_index` | 0.0039 |
| `class_participation` | 0.0002 |
| `attendance_percentage` | −0.0003 |

Only study hours carry signal. The negative value for attendance means shuffling it slightly
*helped* — i.e. noise, not a learned relationship.

## Cross-checks performed

- `src/evaluate.py` reloaded the saved artifacts and recomputed the test metrics: identical to
  the values above (`results/evaluation_rerun.json`).
- `results/predictions.csv` holds all 150,000 test predictions with actual values; its mean
  actual score (84.291) matches `metrics.json`.
- Random sample predictions with actual values:

| student_id | predicted | actual | predicted grade | actual grade |
|---|---|---|---|---|
| 471041 | 85.99 | 85.8 | B | A |
| 206359 | 99.93 | 100.0 | A | A |
| 952263 | 72.25 | 86.2 | C | A |

- Unit tests assert the exact single-student prediction (15 h, 85 %, 6.5 → 86.97, grade A),
  reproducibility, batch/single agreement, monotonicity in study hours, input rejection, and
  that attendance what-ifs stay below one point (the model must not invent attendance signal).
