MARKITDOWN-VALIDATOR  -  HOW TO LOAD AND USE (save this for next session)
=======================================================================

1. WHAT YOU GOT
   markitdown-validator.skill   the skill (zip archive: SKILL.md, scripts/, requirements.txt, README.txt)
   requirements.txt             Python dependencies (also inside the skill)
   sample_validation_report.md  example report from my test run

2. DEFAULT PYTHON VERSION
   Python 3.12.3 (the Claude.ai sandbox default). Works on Python 3.9+.
   Libraries used (versions I tested): markitdown 0.1.5, pdfminer.six 20251230,
   pdfplumber 0.11.9, pypdf 5.9.0, PyYAML 6.0.3.

3. LOAD THE SKILL FOR THE NEXT SESSION

   A) Claude.ai (web/app)
      - Open the presented markitdown-validator.skill file card and click "Save skill"
        (or Settings > Capabilities > Skills > upload the .skill file).
      - In any new chat just attach the PDF + MD and say:  /markitdown-validate
        (or simply "validate this markdown against the PDF").

   B) Claude Code - automatic loading (skills folder is scanned at startup)
      mkdir -p ~/.claude/skills
      unzip markitdown-validator.skill -d ~/.claude/skills/
      -> restart Claude Code, then type:  /markitdown-validator
         (slash command = the skill's folder name; if you want the exact name
          /markitdown-validate, rename the folder AND the `name:` line in SKILL.md.)

   C) Claude Code - project-only install
      unzip markitdown-validator.skill -d ./.claude/skills/

   Install the dependencies once:
      pip install -r requirements.txt

4. USE IT
   In chat:   attach  paper.pdf  +  paper.md   ->   "/markitdown-validate"
   Output:    paper_validated.md  (original + "## Recovered Content" appended, per PDF page)
              paper_validation_report.md / .json  (coverage %, missing blocks, per-page table)

   Command line (no Claude needed):
      python ~/.claude/skills/markitdown-validator/scripts/validate.py --pdf paper.pdf --md paper.md --out-dir ./out
      Flags: --in-place | --dry-run | --generate-md | --threshold 0.8 | --skip-low-signal

   Prove it works on your own document:
      python scripts/selftest.py --pdf paper.pdf --md paper.md

5. KNOWN LIMITS
   - Figures/images have no text, so they are counted but cannot be validated.
   - Equations are recovered as PDF glyph order, not LaTeX (marked "low-signal").
   - Scanned PDFs need OCR first.
   - Existing "(cid:NN)" glyph junk in the MD is reported, not auto-repaired.
